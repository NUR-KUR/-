# ULTIMA

Каталог салонов Москвы: тёмный интерфейс, мобильная версия, фильтры по району и услугам, карточки филиалов, избранное и единая история посещений.

**[Открыть сайт](https://nur-kur.github.io/-/)**

## Версия для просмотра

Сайт GitHub Pages расположен в `docs/`. Он работает без сборки, регистрации и внешнего API. Демопрофиль, планы, посещения и оценки сохраняются в браузере посетителя. Эти данные не синхронизируются между устройствами и не становятся общими отзывами. Реальная запись открывается на официальном сайте салона; сохранённый план не является бронью.

В каталоге 22 адреса. Кандидаты и карточки, требующие уточнения, отмечены отдельно. Источники и происхождение фотографий доступны в интерфейсе. Изображения салонов принадлежат соответствующим правообладателям.

## Запуск локально

```sh
python3 -m http.server 8080 --directory docs
```

Открыть http://localhost:8080.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → `main` → `/docs` → Save.

## Серверные исходники

В корне сохранена исходная реализация на Vinext / Cloudflare Workers с базой D1. Она отделена от демонстрации Pages и требует собственного серверного окружения и доверенной авторизации. Инструкция и ограничения — в [README-server.md](README-server.md). Секреты, база пользователей и служебные параметры исходного хостинга в репозиторий не включены.
